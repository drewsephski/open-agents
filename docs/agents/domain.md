# Domain Docs

This repository uses a single domain context.

## Before exploring

- Read the root `CONTEXT.md`.
- Read relevant ADRs under `docs/adr/`.
- If either is absent, continue silently.

## Vocabulary

Use canonical terms from `CONTEXT.md` in issues, specifications, tests, plans, and implementation discussions. Avoid synonyms that the glossary explicitly rejects.

## Architectural decisions

Surface conflicts with existing ADRs explicitly. Do not silently override them.

Domain documents are created and updated lazily as terminology and hard-to-reverse decisions are resolved.
